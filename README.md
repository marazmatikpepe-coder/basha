# Башня помнит

Запуск: открыть `index.html` двойным кликом (папка `assets` должна лежать рядом).

Сборка установщика Windows: залить папку на GitHub, вкладка Actions → Build Windows installer → скачать `.exe`.

Музыка по областям задаётся в `audioTick` (index.html), звуки — в `smap`. Файлы лежат в `assets/audio`, текстуры и спрайты — в `assets/img`.
